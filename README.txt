MEHEBUBA PARVIN - PERSONAL PORTFOLIO

1. Extract this ZIP file.
2. Open the extracted Portfolio folder in Visual Studio Code.
3. Open index.html in a browser (double-click it), or use the VS Code Live Server extension.
4. The navigation links connect the four HTML pages.
5. Replace or update any content that does not accurately describe your own skills or project contributions.
6. The contact form currently demonstrates front-end validation only. It does not send or store messages. A backend or form service is needed for real submissions.
7. For the assignment, take your own screenshots of all four pages in at least two browsers.
8. Upload the folder to your own GitHub repository and enable GitHub Pages to publish the live demo.

Files: index.html, about.html, projects.html, contact.html, style.css, script.js, images/profile.jpg
